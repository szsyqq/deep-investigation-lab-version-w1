主体研究 · ENTITY

围绕主体建立经营与外部验证链

已根据任务生成：调查空客为什么订单创新高，交付和现金流却同时承压

下一步将由主编、分析师、调查员、反方审稿人、数据编辑和读者代表共同形成研究议程，不直接写结论。

  1. 主体如何定义自己，真实收入来自哪里？
  2. 业务、财务、治理和技术之间有何张力？
  3. 监管、客户、同行与数据如何交叉验证？
  4. 哪些事实可能推翻核心论点？

命令行入口：运行 npm run research:new -- “你的研究请求”，即可生成包含讨论、底稿、初稿、审核与发布状态的独立研究包。
